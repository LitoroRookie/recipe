# 🌿 植物魔法配方網站

一個使用 **Laravel 10 + Tailwind CSS** 開發的食譜分享平台，靈感來自魔法世界的植物藥劑與配方。  
使用者可以建立、編輯、刪除、瀏覽自己的配方，也能探索其他人的創作並搜尋想要的食譜。  

---

## ✨ 功能特色

- **使用者系統**
  - 註冊 / 登入 / 登出
  - 自動登出機制（閒置超過 1 小時）
- **配方管理**
  - 新增、編輯、刪除自己的植物魔法配方
  - 上傳配方圖片
- **探索配方**
  - 查看所有使用者公開的配方
  - 搜尋配方名稱
- **介面設計**
  - 使用 Tailwind CSS 打造清新魔法風格
  - 響應式設計，手機與桌機皆可使用
- **其他**
  - Blade 模板結構化
  - 右上角下拉選單快速進入帳戶相關功能

---

## 🛠 技術棧

- **後端框架**: Laravel 10
- **前端框架**: Blade + Tailwind CSS
- **資料庫**: MySQL / MariaDB
- **圖片上傳**: Laravel Storage
- **部署平台**: Railway（免費方案）
